# lets hoop!

A comprehensive basketball general manager simulation game with season-by-season career history tracking, player comparisons, and advanced roster management.

## Quick Start

### Prerequisites
- Node.js (v14 or higher)
- A modern web browser (Chrome, Firefox, Safari, or Edge)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/nettops/Basketball-GM.git
cd Basketball-GM
```

2. Open the game in your browser:
```bash
open index.html
```
Or simply double-click `index.html` in your file explorer.

### Features

- **Career History System**: Track player performance season-by-season with detailed statistics, contract history, and injury records
- **Player Profiles**: View comprehensive career stats, season breakdowns, team history, and injury timelines
- **Player Comparison**: Compare 2-4 players side-by-side with stat progression charts and head-to-head analysis
- **Career Ledger**: Search and filter player statistics across the entire league with CSV export
- **Roster Management**: Draft, trade, and sign players to build your championship team
- **Season Simulation**: Simulate games with realistic player performance and career progression

## Development

No build process required—all JavaScript runs in the browser. Edit files directly and refresh the page to see changes.
